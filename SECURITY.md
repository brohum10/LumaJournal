# Security Policy

Luma Journal handles private journal text, speech input, and optional EventKit writes. Reports involving unintended data transmission, permission bypasses, unsafe generated actions, or data exposure are especially important.

Please do not open a public issue for a vulnerability. Use GitHub's **Security → Report a vulnerability** flow when available. Otherwise, contact the maintainer through the GitHub profile and include the affected version, reproduction steps, impact, and suggested mitigation.

The current `main` branch is the supported version. Security fixes are prioritized, but this project does not currently publish a formal response-time guarantee.
